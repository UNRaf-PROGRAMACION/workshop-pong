# Workshop: getting started

1. Review the paths that would be created: `npx create-agent-ready-unraf . --level=sdd --workshop --dry-run`.
2. Apply the scaffold only after reviewing those paths: `npx create-agent-ready-unraf . --level=sdd --workshop`.
3. Complete the game idea or bring an existing GDD.
4. Define one small spec before asking an agent to edit code.
5. Inspect the plan, approve the scope, and retain evidence.
